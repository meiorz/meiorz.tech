Archive

These pages are saved from my first website, meiorz.github.io. It started as a copy of the sample project from the Learn Enough CSS & Layout tutorial, and I used it as a blog from 2021 to 2023.

  • blog/ Six blog posts, September 2021 to March 2023.
  • home-2023.html A text copy of the old home page.

How it was archived

  • The post text is unchanged, typos included. Links to the old Notion pages are gone; an archive note marks each spot.
  • Removed: Google Analytics, web and icon fonts, third-party embeds, and the avatar image and Twitter link from each byline.
  • Images that had expired or were hotlinked are gone, and so are header images and stickers built from someone else’s artwork, logos or emoji. An archive note marks each spot.
  • Every archive page asks search engines not to index it.

Not archived

The old photo gallery page, an exercise from the Learn Enough JavaScript tutorial, is not archived.
