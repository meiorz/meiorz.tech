BlobGuard in progress

An AI-assisted (agentic) engineering project on a real problem: cloud storage security. BlobGuard is an open-source (MIT) security posture scanner for cloud object storage, a Python command-line tool (Python 3.12 or newer). I own and direct the project; it’s built with an AI-assisted (agentic coding) workflow.

  • Read-only: management (control-plane) APIs only. It never reads object contents.
  • Every finding carries evidence and a remediation.
  • Checks that can’t be confirmed report error, never pass.
  • Provider-abstraction design: the Azure adapter is in progress (initial checks landing); AWS and GCP adapters are planned behind the same interface.
  • Signs in with DefaultAzureCredential, so it never handles secrets itself.
  • Commands: blobguard scan, explain, list-checks. Reports in JSON or Markdown.
  • Exit codes that can gate a pipeline: 0 clean, 1 failing finding, 2 bad usage, 3 could not run.
  • Sandbox-only lab resources (Terraform on Azure) with dummy data. GitHub Actions CI runs the automated tests.

Python · Terraform · Azure · GitHub Actions · github.com/meiorz/blobguard
